# 🏏 IPL Score Predictor
A Machine Learning project that predicts the **IPL first-innings score** using match details such as teams, venue, overs, and wickets.

### 🛠️ Tech Stack
* Python
* Pandas & NumPy
* XGBoost
* TensorFlow/Keras
* Streamlit

### 🚀 Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
